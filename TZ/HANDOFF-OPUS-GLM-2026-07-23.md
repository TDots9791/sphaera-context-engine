### P1-A. Гранулярный документный граф (`document_graph_granular`) — фундамент рва
ВАЖНО (реконсиляция с дисциплиной §3): НЕ фрагментировать ретрив-ИНДЕКС. Вместо этого —
ПАРАЛЛЕЛЬНЫЙ документ-структурный ГРАФ: узлы {file→page→section→table} с локаторами для
НАВИГАЦИИ/визуализации/точных ссылок, а BM25-индекс остаётся на цельных записях + delivery-trim.
Быстрый мост §4: import host-чанков UniParPro (`ocr_chunks/page_NNN.json`, 233 стр/PDF).
Плюс: поднять/авто-поднять `max_file_bytes` для документов (7МБ PDF молча выпадал).

### P1-B. Живой граф знаний код+документы + визуализация (`living_knowledge_graph`)
На гранулярном фундаменте: рёбра mentions/cites/derived_from(активность через observe+lineage)/
implements/similar_topic(порог). `graph viz` → self-contained HTML (подграф-фокус, слои, фильтры)
+ экспорт GraphML/DOT. Proof-of-concept уже есть (артефакт: 143 наших дока, 501 ребро из ссылок).

### P2. Супер-граф (`supergraph_federation`) — ПОСЛЕ стабилизации одиночного движка
MVP: пул verified capability + верификация (авто-повтор/стандарт, approve текста) + recall-task.
§11 датасет — OWNER-PRIVATE, НЕ в дистрибутив, allow-list только обобщённое.

### Точечное (когда сеть/приоритет позволят)

в `DIFFERENTIATORS.md` (ограниченные утверждения).
